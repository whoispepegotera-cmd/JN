# Remaining work
This publication is playable but does not meet the original full-game definition of done.
- No server, database, account registration/login or cloud save. Saves depend on this browser/site origin.
- Offline progress uses local time (8-hour cap); it is not secure or server-authoritative.
- No competitive leaderboard, guilds, purchases, seasons, multiplayer or authoritative anti-cheat.
- The required canonical production DOCX, art PDF and asset specification are absent from this checkout.
- Worlds/names come from existing game source; content completeness/canonical balance is unverified.
- 30 item templates, 45 normal enemy names and shared runtime enemy images fall short of requested content counts.
- Both supplied WebP atlases are truncated. Supplied complete Mara/hound/boss images are used whole;
  independent SVG scenery and UI symbols are provisional, recorded in asset-provenance.json.
- Current code is standalone JavaScript; the requested TypeScript monorepo/Pixi/React/Fastify/Postgres stack remains pending.
- Multi-tab concurrent play has no cross-tab transaction authority. Use one game tab per browser.
